**Title:** TI-Nspire CAS for Claude: exact math, LaTeX solving and Notes pages

**Short description:**
Turn the TI-Nspire CX CAS on your PC into your agent's math engine. This skill
teaches Claude when to hand math to the CAS instead of answering from memory,
how to use each tool of the free `nspire` MCP server (evaluate, batch, LaTeX,
Notes pages), and how to avoid the pitfalls: stored variables, the clipboard
transport, and keeping the bridge page open. Get exact answers to integrals,
limits, systems, ODEs and matrices, solve pasted LaTeX, and have worked
solutions typed onto a live TI-Nspire Notes page.

**Requires:** the `nspire` MCP server (free, https://github.com/villejokinen/nspire-mcp),
Windows 10 or 11, and TI-Nspire CX CAS Student or Teacher Software (licensed
separately from Texas Instruments).

**Suggested price:** free to start (to collect installs and feedback), or $5.

**Note to buyers:** The `nspire` MCP server this skill uses is free to
download from GitHub (source available; all rights reserved by the author, free for
personal, non-commercial use; see LICENSE in the repo).
You don't need to buy this skill to install it. This
skill adds the agent-side know-how: when the CAS is worth calling, which tool
fits which request, TI-Nspire syntax hints, how to check steps before writing
a Notes page, how to spot and clear stored variables, and what to do when the
bridge stops answering, plus setup, troubleshooting and example references.
TI-Nspire software is not included and must be licensed by you.
